# Política de Seguridad

## Versiones Compatibles
| Versión | Soportada |
| :--- | :--- |
| 1.0.x | :white_check_mark: |

## Reportar una Vulnerabilidad
Si detectas alguna vulnerabilidad de seguridad en este repositorio, por favor repórtala de manera responsable antes de abrir una incidencia pública.

## Buenas Prácticas de Seguridad
- No almacenar credenciales, llaves API, tokens ni cadenas de conexión en el historial de Git.
- Utilizar variables de entorno protegidas (`.env`).
- Mantener dependencias actualizadas mediante auditorías regulares (`npm audit`).
- Implementar sanitización de entradas y protección contra ataques comunes (XSS, SQLi, CSRF).
